01

Core Concepts

These four nest inside each other like Russian dolls — exactly as the hero diagram above shows. Get these right and everything else clicks faster.

Artificial Intelligence (AI)

Systems that do things that normally need a human brain: reasoning, learning, deciding.

Machine Learning (ML)

A type of AI that learns patterns from data instead of following step-by-step rules.

Deep Learning (DL)

ML that uses many layers of neural networks to learn complex things from huge datasets.

Neural Network

Connected nodes (like brain cells) organised in layers that process information.

Test yourself

Is every ML system also AI, or is every AI system also ML?

Show answer
Every ML system is AI — but not every AI system is ML. ML sits inside AI (see the nested circles). A classic chess engine or a rule-based expert system is AI without any learning: it follows hand-written rules, so it isn't ML.
02

How Models Learn

The method depends on what kind of data you have.

Supervised Learning

You give it labelled examples ("this is a cat, this is a dog") and it learns the pattern.

Unsupervised Learning

No labels. The model finds hidden patterns on its own.

Reinforcement Learning (RL)

Trial and error. Rewards for good moves, penalties for bad ones.

Self-Supervised Learning

The model makes its own labels from the data (like hiding a word and predicting it).

Transfer Learning

Take what a model learned on one task and apply it to a different one.

Fine-Tuning

Take a pre-trained model and train it a bit more on your specific task.

Zero-Shot Learning

The model does a task it was never trained on. No examples needed.

Few-Shot Learning

You give it 1 to 10 examples and it figures out the pattern.

RLHF

Reinforcement Learning from Human Feedback. Humans rate outputs, model learns what people prefer.

Test yourself

ChatGPT summarises a legal contract it was never trained on. Zero-shot or few-shot?

Show answer
Zero-shot. You gave it no worked examples of contract summaries — just the instruction and the document. The moment you paste in one or two example summaries to copy the style from, it becomes few-shot.
03

Architecture & Training

What models are made of and how training actually works under the hood.

Transformer

The architecture behind ChatGPT, Claude, Gemini. Uses attention to understand context.

Large Language Model (LLM)

A neural network trained on massive text to understand and generate language.

Foundation Model

A big base model trained on broad data, adaptable to specific jobs.

Parameters

The adjustable weights inside a model. More = more capable (and expensive).

Hyperparameters

Settings you choose before training: learning rate, batch size, number of layers.

Training Data

The dataset used to teach the model. Quality in, quality out.

Epoch

One full pass through the entire training dataset.

Batch Size

How many examples the model sees before updating its weights.

Loss Function

The scorecard. Measures how wrong the model's guess was.

Gradient Descent

Adjust weights in the direction that reduces the loss. How models get better.

Backpropagation

Errors flow backward through the network so every layer learns from its mistakes.

Attention

Lets the model focus on the most relevant parts of the input. The key idea behind transformers.

Tokenisation

Chopping text into small pieces the model can process. "Don't" becomes ["Don", "'t"].

Test yourself

Parameters vs hyperparameters: which ones does the model learn on its own?

Show answer
Parameters. The model adjusts its weights automatically through the training loop above (loss → backprop → gradient descent). Hyperparameters — learning rate, batch size, layer count — are set by humans before training starts and never learned.
04

Generative AI

The category most people interact with today. AI that creates, not just classifies.

Generative AI

AI that creates new content: text, images, audio, video, code.

Prompt

The instruction you type to tell the model what to do.

Token

A small chunk of text. One word is roughly 1–2 tokens.

Context Window

How many tokens the model sees at once. Bigger = more conversation fits.

Temperature

The creativity dial. High = random, creative. Low = predictable, safe.

Inference

When the model runs and gives you an answer. Training teaches, inference performs.

Diffusion Model

Turns noise into images. How DALL-E and Midjourney work.

Autoregressive Model

Generates one token at a time, each based on all before it. How ChatGPT writes.

Test yourself

You want Claude to write a creative story. Temperature high or low?

Show answer
High. A higher temperature makes token choices more varied and surprising — exactly what creative writing needs. Keep it low when you need factual, consistent, or structured output like code or data extraction.
05

AI Agents & Systems

When AI stops answering and starts doing.

AI Agent

A system that sees, thinks, and acts on its own toward a goal.

Agentic AI

AI that plans multi-step tasks, picks tools, executes independently.

Tool Use

AI calling external tools (search, calculator, APIs) to get the job done.

Chain-of-Thought (CoT)

Prompting the model to think step by step instead of jumping to the answer.

RAG

Retrieval-Augmented Generation. Searches real documents before answering to stay grounded.

MCP

Model Context Protocol. Open standard letting AI plug into external tools and data.

Test yourself

What separates an AI agent from a chatbot?

Show answer
Action and autonomy. A chatbot responds when you talk to it — one message in, one answer out. An agent pursues a goal: it plans multiple steps, picks and calls tools (search, APIs, code), checks its own results, and keeps going without you prompting each step.
06

NLP & Language

Teaching machines to work with human language — by turning words into geometry.

NLP

Natural Language Processing. Teaching machines to understand human language.

Embedding

Turning text into numbers so the model can do maths on meaning.

Semantic Search

Search by meaning, not exact words. "Affordable car" finds "budget vehicles".

Tokenization

Splitting text into tokens the model can process.

Attention Mechanism

How the model decides which parts of the input matter most.

07

Vision & Multimodal

Teaching AI to see — and to handle text, images, and audio in one model.

Computer Vision

Teaching AI to see and understand images.

Multimodal AI

Text, images, and audio all at once. Claude reading a screenshot is multimodal.

OCR

Optical Character Recognition. Photo of text becomes editable text.

Image Segmentation

Splitting an image into separate objects or regions.

Object Detection

Finding and labelling things inside an image.

08

What Can Go Wrong

The failure modes. Knowing these makes you a sharper user.

Hallucination

Makes something up and presents it as fact. Sounds confident, completely wrong.

Overfitting

Memorised training data so well it cannot handle anything new.

Underfitting

Too simple to learn the patterns.

Bias

Systematic unfairness from training data or design choices.

Alignment

Making sure AI does what humans actually want.

Jailbreaking

Tricking a model into ignoring its safety rules.

Prompt Injection

Sneaking instructions into input data to hijack the model.

Ground Truth

The verified correct answer you compare the model against.

Test yourself

Claude cites a paper that does not exist. Hallucination, bias, or prompt injection?

Show answer
Hallucination. The model fabricated a plausible-sounding source and presented it as fact. Bias would be systematic unfairness; prompt injection would require hidden instructions smuggled into the input. Neither is happening here.
09

Evaluation & Metrics

How you score a model. Is it actually good or just looks good?

Benchmark

A standardised test to compare models. Like an exam everyone sits.

Accuracy

How many answers the model got right out of all answers.

Precision

When the model says "yes", how often is it actually right?

Recall

Of all actual positives, how many did the model catch?

F1 Score

Precision and recall balanced into one number.

Perplexity

How surprised the model is by the next word. Lower = understands language better.

BLEU Score

Scores generated text against a human-written reference.

10

Safety & Ethics

Keeping AI understandable, testable, and accountable.

Explainable AI (XAI)

Understanding why the model made a decision.

Red Teaming

Deliberately breaking the model to find weaknesses before users do.

Constitutional AI

Training with a set of principles the model must follow.

Guardrails

Hard limits on what the model can and cannot output.

Data Privacy

Protecting personal information in training and inference.

Model Card

A fact sheet: what it can do, what it cannot, how it was trained.

Watermarking

Hidden markers so you can tell if something was AI-generated.

11

Infrastructure & Deployment

The plumbing. How models run, get faster, and what hardware powers them.

API

A way for your code to talk to an AI model. Question in, answer back.

Latency

Time between pressing enter and getting a response.

Throughput

How many requests the system handles at once.

GPU

The chip behind AI training. Originally for graphics, now the engine behind every major model.

TPU

Google's custom chip for AI workloads.

Quantization

Shrink the model by reducing number precision. Faster, cheaper, slightly less accurate.

Distillation

A big model teaches a small model. Student keeps most ability at a fraction of the cost.

Edge AI

Running AI on your device instead of in the cloud.

Synthetic Data

Fake data generated by AI to train other AI.

12

Advanced Concepts

The frontier. Research papers, product launches, and debates about where AI is heading.

Latent Space

A compressed map where the model stores meaning. Similar things sit close together.

Emergent Abilities

Skills that appear when a model gets big enough. Nobody programmed them in.

Scaling Laws

More data + more compute + bigger model = better results. Predictably.

In-Context Learning

Model learns from examples in the prompt. No retraining needed.

Mixture of Experts (MoE)

One big model, many specialists inside. Only relevant experts activate per query.

AGI

Artificial General Intelligence. Hypothetical AI as smart as a human across every domain. Does not exist yet.

ASI

Artificial Superintelligence. AI smarter than all humans combined. Theoretical.

Test yourself

GPT-4 does maths, writes poetry, debugs code. Nobody trained it for each one. What is that?

Show answer
Emergent abilities. These skills weren't individually programmed or trained — they appeared once the model crossed a scale threshold (see the orange dots in Fig. 7). It's the surprising flip side of the otherwise-predictable scaling laws.
